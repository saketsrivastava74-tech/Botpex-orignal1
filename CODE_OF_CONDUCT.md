# Code of Conduct

## Our standard

The Botpex community works to build shared infrastructure for Minecraft bot development. Participants
are expected to be professional, honest and constructive:

- **Be accurate.** Do not claim implemented functionality that is not implemented; do not misrepresent
  test results or benchmarks. (This mirrors the project's core engineering rule.)
- **Be constructive.** Critique designs and code, not people. Explain trade-offs.
- **Respect licenses and server operators.** Do not promote tools or techniques whose primary purpose
  is to violate Minecraft server rules, Mojang's EULA, or third-party licenses (x-ray, denial-of-service
  botting, account theft, license laundering).
- **No harassment.** Insults, discriminatory language, sexualized content, stalking or doxxing are not
  tolerated anywhere in project spaces (issues, PRs, chat, events).
- **No spam or advertising.** Distributing your own bot on top of Botpex is welcome; advertising in
  unrelated threads is not.

## Scope

Applies to all project spaces: repository (issues, PRs, discussions), official chat channels, and
events representing the project. It also applies when an individual represents the project publicly.

## Enforcement

Report violations to the maintainers via the contact listed in SECURITY.md (or a private GitHub message
to a maintainer). Reports are handled confidentially.

Possible consequences, proportionate and at maintainer discretion: private warning → temporary
muting/review hold → permanent ban from project spaces. Decisions can be appealed to the maintainers
as a group.

Maintainers are held to the same standard; violations by maintainers should be reported to another
maintainer and, if it involves all maintainers, to the project's Code of Conduct committee (see
GOVERNANCE as it evolves).

## Attribution

This document is an original, concise code of conduct written for Botpex. Projects that prefer the
industry-standard long-form text may adopt the Contributor Covenant themselves, provided they keep its
