# hello-bot

The smallest useful Botpex bot: perceives entities, greets nearby players,
wanders, and logs navigation/chats.

```bash
npm run start                 # mock runtime (deterministic, no server)
npm run start:native          # real server (set --host/--username)
```

Switching runtimes demonstrates Botpex's core promise: **the same bot code
runs on any runtime** — capabilities are negotiated at start.
